DELÍCIAS DA VÓ — PUBLICAÇÃO SEGURA DA V5.3

1. ANTES DE SUBSTITUIR OS ARQUIVOS
Abra o terminal do VS Code na pasta atual do projeto e execute:

git switch main
git pull origin main
git switch -c melhoria-perfil-mapas-v5-3

2. SUBSTITUA OS ARQUIVOS
Extraia este ZIP e copie o conteúdo para a pasta atual do projeto.
Aceite substituir os arquivos existentes.
Não copie uma pasta .git e não crie outra pasta dentro do projeto.

3. ENVIE SOMENTE A BRANCH DE TESTE

git add .
git commit -m "feat: adiciona perfil, contatos e taxa de entrega automática"
git push -u origin melhoria-perfil-mapas-v5-3

4. ATIVE O CÁLCULO AUTOMÁTICO NA PREVIEW
Crie uma chave gratuita em:

https://myprojects.geoapify.com/

Depois abra o projeto na Vercel:
Settings > Environment Variables > Add New

Name:
GEOAPIFY_API_KEY

Value:
cole a chave criada no Geoapify

Marque Preview e Production, salve e mande a Vercel refazer o deploy da branch.
Não coloque essa chave em arquivo, no GitHub ou no index.html.

Abra a Preview criada pela Vercel e teste:
- carrinho;
- rolagem do carrinho com o navegador em 100% de zoom;
- login Google e botão Dados;
- busca por CEP;
- selecione Entrega, preencha o endereço e confirme se distância, taxa e total aparecem;
- confira R$ 5,00 até 3 km e R$ 7,00 acima de 3 km até 5 km;
- WhatsApp;
- Endereço da loja;
- Instagram da loja;
- painel administrativo no celular e no computador.

5. DEPOIS DE APROVAR A PREVIEW

git switch main
git pull origin main
git merge --no-ff melhoria-perfil-mapas-v5-3 -m "merge: publica melhorias da V5.3"
git push origin main

6. SOMENTE DEPOIS DE CONFIRMAR A PRODUÇÃO

git branch -d melhoria-perfil-mapas-v5-3
git push origin --delete melhoria-perfil-mapas-v5-3

FIREBASE
Esta atualização não precisa de novas regras. Se as regras da V5.2 já estão
publicadas, não faça outro deploy do Firebase.

OBSERVAÇÃO
O endereço completo da loja precisa estar salvo em Painel > Configurações. O sistema
usa esse endereço como ponto de saída para calcular a rota até o cliente.
