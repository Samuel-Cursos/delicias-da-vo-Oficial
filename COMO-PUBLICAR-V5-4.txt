DELÍCIAS DA VÓ — PUBLICAÇÃO SEGURA DA V5.4

1. ANTES DE SUBSTITUIR OS ARQUIVOS
Abra o terminal do VS Code na pasta atual do projeto e execute:

git switch main
git pull origin main
git switch -c melhoria-scanner-cursiva-v5-4

2. SUBSTITUA OS ARQUIVOS
Extraia este ZIP e copie o conteúdo para a pasta atual do projeto.
Aceite substituir os arquivos existentes.
Não copie uma pasta .git e não crie outra pasta dentro do projeto.

3. ENVIE SOMENTE A BRANCH DE TESTE

git add .
git commit -m "feat: adiciona leitura rápida de vendas manuscritas"
git push -u origin melhoria-scanner-cursiva-v5-4

4. CONFIRA A VERCEL
No projeto da Vercel, abra Settings > Environment Variables.
Confirme que GEMINI_API_KEY está marcada para Preview e Production.
Não coloque a chave no GitHub, no index.html nem em arquivos do projeto.

Abra a Preview criada pela Vercel e teste:
- entrar no painel com a conta administradora;
- Digitalizar registros > Venda;
- fotografar uma venda manuscrita e conferir se a leitura começa sem recorte;
- testar uma letra cursiva com valor e forma de pagamento visíveis;
- conferir o valor antes de salvar;
- tocar em Usar leitura local para conferir a alternativa;
- Digitalizar registros > Compra e testar uma nota impressa;
- confirmar que Caixa e Financeiro recebem o registro correto;
- testar no celular e no computador.

5. DEPOIS DE APROVAR A PREVIEW

git switch main
git pull origin main
git merge --no-ff melhoria-scanner-cursiva-v5-4 -m "merge: publica scanner manuscrito da V5.4"
git push origin main

6. SOMENTE DEPOIS DE CONFIRMAR A PRODUÇÃO

git branch -d melhoria-scanner-cursiva-v5-4
git push origin --delete melhoria-scanner-cursiva-v5-4

FIREBASE
Esta atualização não precisa de novas regras nem de outro projeto Firebase.

PRIVACIDADE
A foto de venda é reduzida no aparelho e enviada ao Gemini para leitura. O código do
site não salva essa foto. Evite fotografar CPF, telefone ou outros dados pessoais.
