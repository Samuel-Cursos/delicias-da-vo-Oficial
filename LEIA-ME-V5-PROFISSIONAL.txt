DELÍCIAS DA VÓ — V5.3 PROFISSIONAL

Esta versão mantém a mesma identidade, a mesma logo e o mesmo jeito simples de
fazer pedidos. Os produtos continuam usando emojis; nenhuma foto real foi
adicionada ao site.

PRINCIPAIS MELHORIAS DA V5.3
- O painel agora separa o nome visível e a URL do Google Maps.
- O painel agora separa o nome visível e a URL do Instagram.
- O cliente vê apenas nomes simples, como "Endereço da loja" e "Instagram da loja".
- Nova área de contato rápido com WhatsApp, Google Maps e Instagram.
- Nova área "Meus dados" para o cliente editar nome, WhatsApp e endereço.
- Busca de endereço pelo CEP no perfil, pedido normal e encomenda para festa.
- Dados salvos no perfil continuam preenchendo automaticamente os próximos pedidos.
- A V5.3 não exige alteração nova nas regras do Firebase.

MELHORIAS PRESERVADAS DA V5.2
- Carrinho continua aberto ao adicionar, aumentar, diminuir ou editar itens.
- Pedido normal não depende mais de um contador público bloqueado pelo Firebase.
- Pedidos normais e encomendas recebem códigos únicos e fáceis de identificar.
- Login Google do cliente preenche nome, telefone e endereço já salvos.
- Após o primeiro pedido logado, os dados ficam prontos para as próximas compras.
- Cliente sem login continua podendo montar e enviar pedidos normalmente.
- Regras impedem que um cliente se transforme em administrador.
- API da IA aceita chamadas somente do e-mail administrador.
- Logo da página foi reduzida de aproximadamente 2,2 MB para 128 KB sem trocar a arte.
- Animação da logo aparece somente uma vez por sessão e abre mais rápido.
- Seção de promoções fica escondida quando não existem ofertas ativas.
- Textos técnicos do Firebase e do painel foram removidos da loja.
- Endereço, WhatsApp e Instagram aparecem como links no rodapé.
- Horário da loja usa o fuso de São Paulo, independentemente do aparelho do cliente.
- Melhorias de acessibilidade, busca, compartilhamento e instalação do aplicativo.

PARA ABRIR LOCALMENTE
1. Extraia todo o ZIP.
2. Abra a pasta no VS Code.
3. Use a extensão Live Server e clique em "Go Live".
4. Loja: index.html
5. Administração: pages/admin.html

ATUALIZAÇÃO SEGURA DO GITHUB E DA VERCEL
Use sempre uma branch de teste antes da main:
1. git switch main
2. git pull origin main
3. git switch -c melhoria-perfil-mapas-v5-3
4. Substitua os arquivos pelos desta versão.
5. git add .
6. git commit -m "feat: adiciona perfil do cliente, CEP e localização"
7. git push -u origin melhoria-perfil-mapas-v5-3
8. Teste a Preview criada pela Vercel.

Somente depois de aprovar a Preview:
1. git switch main
2. git pull origin main
3. git merge --no-ff melhoria-perfil-mapas-v5-3 -m "merge: publica melhorias da V5.3"
4. git push origin main

Não crie outro projeto da Vercel e não crie outro projeto do Firebase.

REGRAS DO FIREBASE
Se as regras da V5.2 já foram publicadas, não precisa publicar novamente na V5.3.
As instruções abaixo servem apenas para uma instalação que ainda não recebeu as regras.

Pelo terminal do VS Code, dentro desta pasta:
1. npx firebase-tools login
2. npx firebase-tools deploy --only firestore:rules,storage

O projeto já está configurado para: delicias-da-vo-70953

Se preferir o Firebase Console, copie e publique SOMENTE o conteúdo de:
- firestore.rules, nas regras do Firestore Database;
- storage.rules, nas regras do Storage.

Não use os arquivos de regras marcados como históricos.

LOGIN E DADOS DOS CLIENTES
- O login Google é opcional para o cliente.
- No primeiro acesso, o nome da conta Google é preenchido automaticamente.
- Pelo botão "Dados", o cliente pode salvar telefone e endereço antes de pedir.
- Também é possível salvar esses dados ao concluir um pedido logado.
- Cada cliente só consegue ler e atualizar o próprio perfil.

CONFIGURAR MAPS E INSTAGRAM
No painel administrativo, abra Configurações.
- Nome exibido do endereço: texto que aparece no site, por exemplo "Endereço da loja".
- Link do Google Maps: URL que abre quando o cliente clica no nome.
- Nome exibido do Instagram: texto que aparece no site, por exemplo "Instagram da loja".
- Link do Instagram: URL completa do perfil.
Os links precisam começar com https://.

VERCEL
Mantenha a variável GEMINI_API_KEY que já existe no projeto. Nenhuma nova chave é
obrigatória. A rota da IA agora confirma o login do administrador antes de usar a chave.
